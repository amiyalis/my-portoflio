# 🌸 My Portfolio

Welcome to my personal portfolio website! This is my first web development project, showcasing a clean, aesthetic design featuring **glassmorphism**, **light/dark mode toggle**, and fully responsive layouts.

## 🛠️ Tech Stack
- **HTML5** & **CSS3** (Custom Properties, Flexbox, Grid)
- **JavaScript** (Theme toggling & local storage)
- **FontAwesome** (Icons)

## ✨ Features
- 🌗 Interactive **Dark/Light mode** switch (Sleek Black & Pastel Pink vibes)
- 📱 Fully responsive grid for mobile and desktop screens
- 🔗 Direct links to my GitHub and Discord community
